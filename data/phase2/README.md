# data/phase2

This directory does not hold licensed survey rows. Git tracks this note and `MANIFEST.md` only.

Paper A and Paper B read WVS and GPS extracts from the paths named in [DATA.md](../../DATA.md). Those files are not in git. Adapter weights are not in git either. Paper A adapter weights are on Hugging Face `Bonorinoa/SCA2-phase2-adapters`, public behind a gate (see DATA.md).

The analysis scripts live in `paper_a/`. The locked Paper B numbers live in `paper_b/results/`.
