## Labeling decision (freeze this before any new cohort)

Production rule remains `deterministic_sign` in `synthetic_generation/sca2_datagen/relabel.py` and `paper_b/config.py` (`LABELING_RULE`). Paper B's object is that compiler used as an instrument. A different label is a different compiler.

Do not adopt magnitude labels or per-dimension adapters inside this paper. The claim lock parks both as optional protocol papers. Sign-mates are magnitude-close, so putting `|z|` into the label cannot create the within-profile human variation. That variation is not in the GPS coordinate. No relabeling of this anchor recovers people inside the profile.

The labeling change this surface does identify is a **probe-selection rule**, not a training-label rule:

- A new item may be probe-selected only on an imprint dimension (trust, risk taking, positive reciprocity, altruism).
- Patience and negative reciprocity items are reported as missing. They are not candidates for the screen.
- Freeze that rule in writing before any new item text is scored, and before any human on those items is joined.

The one training-label sensitivity already frozen is protocol decision (B): drop pairs with `|z| < 0.10` and refit. That is a margin on the sign rule. It is reported beside the headline, never promoted. It runs only after the bank-robustness cohort, and first on a predeclared subset (one multi-member profile and one singleton), not on all 42.

A sign-shuffle refit is a placebo, not a production strategy. The claim lock treats it as an alternative to the second bank. It is not a third mandatory cohort. If a reviewer forces it, use the same subset rule.

## Checkpoints

Pass means the named contrast is written down and the named artifact exists. A failed checkpoint stops the next GPU spend. It does not authorize a quieter relabel.

### C2 — Second bank exists, before any retrain

New scenario file, hashed, with a manifest: generator, seed, pair count, proof the prompt multiset is identical across the 42, proof labels match `sign_choice`, proof no country name and no WVS wording. Reuse `synthetic_generation/sca2_datagen/relabel.py`. Do not add a new labeling function.

Checkpoint: `verify_gates.py` (or its successor) prints zero label mismatches and a new `bank_run_id`. Training that starts without that id is not the robustness cohort.

### C3 — Retrain and rescore on the old battery

Retrain all 42 on the new bank. Upload each adapter to a new HF revision. Score base and adapters on the frozen stack, model-only. Join humans locally. Run `paper_b/analyze_surface.py` and `paper_b/analyze_phase.py`.

Checkpoint: 42 `run_record.json` files carry the new `bank_run_id`. SHA-256 of each score file matches its manifest. The comparison table against `paper-b-20261011` is written before any sentence about transport.

### C4 — Held-out item battery, scored before humans

New item text, distinct from both training banks and from the 23-item battery. Score the C3 adapters (and the prompt cell, if C1 exists) with country-free prompts. Apply the probe-selection rule from the labeling decision. Do not join human rows in this step.

Checkpoint: a frozen list of probe-selected items, with the dimension each item was allowed to represent, written before the human file is opened.

### C5 — Human criterion on those items only

Humans come from the route named in C0. The join is local. Skipped cells are named. No respondent file goes to the Hub.

Checkpoint for transport: on the probe-selected items, adapter–GPS is reported only beside human–GPS / imprint / missing. An imprint dimension whose new-battery interval includes 0 is not transport.

Checkpoint for pre-piloting: the probe-selected set differs from the set a human-only rule would have kept, on the same items, with the human-only rule declared before the join. If C0 could not name a human route, this checkpoint stays open and the claim is not written.

### C6 — Near-zero margin, subset only

Refit the predeclared subset on the C2 bank with `|z| < 0.10` pairs removed. Do not filter scored outcomes after the fact.

Checkpoint: a sensitivity table. If the subset's imprint correlations flip sign relative to C3, say so and do not promote the filter. If they do not, the margin stays a footnote.

- A new generator that leaks country names or WVS wording makes C3 incomparable. The C2 hash gate is the stop.
