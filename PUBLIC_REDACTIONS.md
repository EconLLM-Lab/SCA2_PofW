# PUBLIC_REDACTIONS.md

The public copy changes a few files on export. Each row gives the file's sha256 in the lab repository, its
sha256 here, and the change. Researchers rebuild the removed values from the data they download (DATA.md).

- GPS (decision B, 2026-11-04): sign labels only; no continuous country z-scores. Rebuild z from
  `data/GPS/GPS_dataset_country_level/country_gps.dta`.
- Model-to-human distances (decision C, 2026-11-04): no cell- or country-level values. Rebuild the `tvd`
  column with `paper_a/tvd_rebuild.py` from the WVS and GPS downloads.
- WVS wording (decision A1, 2026-11-14): our prompt text ships with attribution (THIRD_PARTY_NOTICES.md);
  verbatim questionnaire columns that no prompt reads are removed.
- Rows marked `withheld` are files kept out of this release. Their lab sha256 is given so a lab copy can be
  checked against it; the reason is the rule that withheld them.
