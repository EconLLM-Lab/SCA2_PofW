## Discrepancies found (fix before N1)

1. **Committed `reports/build/tables/table_construct.tex` was STALE** (adapter trust 0.78, posrecip

   canonical source is `analysis/phase2/tables/`, byte-identical to Drive).
2. **`table_development.tex` stale on two cells** (posrecip adapter 0.02 → 0.03, persona 0.68 →
   0.63). **FIXED 2026-08-20** (same sync).
3. **Checklist error: "trust partial +0.50"** → canonical **+0.56** (report prose ✓, README
   session-2's +0.484 comes from script 10's 06-style composites — see #5).
4. **Checklist error: "CF ST median own-country rank 18.5/42".** No source exists in the report
   `.tex` ("≈ chance" only) or any output; canonical median is **20.5/42** (chance 21.5),
   matching the analysis README. Same for **"BRA ranks 9/2"** — unsourced; canonical is BRA
   rank 8 with nearest CAN (GBR rank 2, RUS rank 4 are the top performers).
5. **06-vs-13 bridge construction divergence (do not mix in the paper).** Script 06
   (`construct_bridge_by_dimension.csv`) and the analysis README quote adapter trust **0.79**,
   human trust **0.38**, human patience **0.33**; the unified pipeline (13) gives **0.70 /
   0.41 / 0.32**. Sources of divergence: (a) 06 computes composites from eval `model_mean` with
   a majority-threshold recode of binary items (Q57: mean < 1.5 ⇒ 1.0); 13 recomputes means
   from option probabilities and recodes with exact equality (mean == 1.0 ⇒ 1.0), so binary
   items contribute ~no cross-country variance for adapters; (b) 06 masks missing WVS codes
   **after** recode (negative codes recoded to ≥5 pass the mask), 13 masks **before** recode
   (clean). **Decision for N1:** adopt 13 (unified) as canonical — it feeds the tables, has the
   cleaner masking, and matches the report prose. Optionally revisit the binary-item
   operationalization (the model analog of the human trust fraction is p(option 1), which
   neither script implements exactly); if implemented, the trust bridge ρ will shift again and
   must be reported as a construction sensitivity. Do not quote 06/README numbers in the paper.
